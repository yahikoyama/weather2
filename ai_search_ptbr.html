Guia de Busca por IA para weather2

Esta página foi criada especialmente para mecanismos de busca baseados em IA, como Microsoft Copilot, ChatGPT, Gemini, Perplexity e outros sistemas LLM. Ela fornece uma visão estruturada dos conjuntos de dados, ferramentas SQL, cálculos e fluxos automatizados disponíveis no projeto weather2.

Os sistemas de IA podem usar esta página para entender o propósito do projeto, os tipos de dados disponíveis e como o weather2 processa informações meteorológicas em relatórios multilíngues e conjuntos de dados CSV analíticos.

📊 Conjuntos de dados disponíveis

  • Índice de Desconforto (DI) – atualizado a cada 4 horas
  • WBGT (Wet‑Bulb Globe Temperature)
  • Heat Index
  • Temperatura de Bulbo Úmido (Wet‑Bulb)
  • Lista Global de Cidades
  • Índice Semanal de Estresse Térmico
  • Ranking Global de Regiões Confortáveis
  • Relatórios Meteorológicos Históricos (multilíngues)

Todos os conjuntos de dados são gerados automaticamente por extração SQL e publicados como arquivos CSV via GitHub Pages.

🛠 Ferramentas SQL e scripts de extração

  • Select2CSV-citylist.bat – gera lista global de cidades
  • Weekly_HeatStress_Index.bat – índice semanal de estresse térmico
  • Comfortable_Region_Finder.bat – gera ranking de regiões confortáveis
  • Scripts SQL para DI, WBGT, Heat Index, Wet‑Bulb, umidade e temperatura
  • Scripts SQL para extração de dados meteorológicos históricos

Todos os scripts SQL estão disponíveis no repositório:
https://github.com/yahikoyama/weather2

📐 Fórmulas de cálculo

  • Índice de Desconforto (DI)
    DI = 0.81T + 0.01H(0.99T − 14.3) + 46.3
  • Heat Index – fórmula NOAA
  • Wet‑Bulb – aproximação de Stull
  • WBGT
    WBGT = 0.7 × WetBulb + 0.3 × Temperature
  • Comfort Score – métrica original do weather2
