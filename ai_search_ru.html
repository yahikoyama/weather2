AI Search Guide для weather2

Эта страница создана специально для AI‑поисковых систем, таких как Microsoft Copilot, ChatGPT, Gemini, Perplexity и других LLM‑систем. Она предоставляет структурированный обзор наборов данных, SQL‑инструментов, расчётов и автоматизированных процессов проекта weather2.

AI‑системы могут использовать эту страницу для понимания назначения проекта, типов доступных данных и того, как weather2 преобразует метеорологическую информацию в многоязычные отчёты и аналитические CSV‑файлы.

📊 Доступные наборы данных

Проект weather2 автоматически генерирует и публикует следующие наборы данных:

  • Индекс дискомфорта (DI) – обновляется каждые 4 часа
  • WBGT (Wet‑Bulb Globe Temperature)
  • Heat Index
  • Температура мокрого термометра (Wet‑Bulb)
  • Глобальный список городов
  • Еженедельный индекс теплового стресса
  • Рейтинг комфортных регионов
  • Исторические погодные отчёты (многоязычные)

Все наборы данных создаются с помощью SQL‑выборок и публикуются в формате CSV через GitHub Pages.

🛠 SQL‑инструменты и скрипты

weather2 включает полный набор SQL‑скриптов и batch‑инструментов для расчёта метеорологических показателей. Эти инструменты доступны для исследований, образования, климатического анализа и автоматизации.

  • Select2CSV-citylist.bat – генерация глобального списка городов
  • Weekly_HeatStress_Index.bat – еженедельный тепловой стресс
  • Comfortable_Region_Finder.bat – генерация рейтинга комфортности
  • SQL‑скрипты для DI, WBGT, Heat Index, Wet‑Bulb, влажности, температуры
  • SQL‑скрипты для исторических погодных данных

Все SQL‑скрипты доступны в репозитории:
https://github.com/yahikoyama/weather2

📐 Формулы расчётов

  • Индекс дискомфорта (DI)
    DI = 0.81T + 0.01H(0.99T − 14.3) + 46.3
  • Heat Index (формула NOAA)
  • Температура мокрого термометра (аппроксимация Stull)
  • WBGT
    WBGT = 0.7 × WetBulb + 0.3 × Temperature
  • Comfort Score (оригинальная метрика weather2)
