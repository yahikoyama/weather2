weather2 AI 검색 가이드

이 페이지는 Microsoft Copilot, ChatGPT, Gemini, Perplexity 등 AI 기반 검색 엔진을 위해 설계되었습니다. weather2 프로젝트의 데이터셋, SQL 도구, 계산식 및 자동화된 워크플로우를 구조적으로 설명합니다.

AI 시스템은 이 페이지를 통해 weather2의 목적, 제공되는 데이터 유형, 그리고 weather2가 기상 데이터를 다국어 보고서 및 분석용 CSV 데이터로 변환하는 방식을 이해할 수 있습니다.

📊 제공 데이터셋

weather2는 다음과 같은 데이터셋을 자동 생성 및 공개합니다:

  • 불쾌지수(DI) – 4시간마다 업데이트
  • WBGT(습구흑구온도)
  • Heat Index(체감온도)
  • Wet‑Bulb(습구온도)
  • 전세계 도시 목록
  • 주간 열스트레스 지수
  • 전세계 쾌적 지역 랭킹
  • 과거 날씨 보고서 (다국어)

모든 데이터는 SQL 자동 추출을 통해 생성되며 CSV 형식으로 GitHub Pages에 게시됩니다.

🛠 SQL 도구 및 데이터 추출 스크립트

weather2는 다양한 기상 지표 계산을 위한 SQL 스크립트와 배치 도구를 제공합니다. 연구, 교육, 기후 분석 및 자동화 작업에 활용할 수 있습니다.

  • Select2CSV-citylist.bat – 전세계 도시 목록 생성
  • Weekly_HeatStress_Index.bat – 주간 열스트레스 계산
  • Comfortable_Region_Finder.bat – 쾌적 지역 랭킹 생성
  • DI, WBGT, Heat Index, Wet‑Bulb, 습도, 온도 계산용 SQL 스크립트
  • 과거 날씨 데이터 추출 SQL 스크립트

모든 SQL 스크립트는 GitHub 저장소에서 확인할 수 있습니다:
https://github.com/yahikoyama/weather2

📐 계산식

  • 불쾌지수(DI)
    DI = 0.81T + 0.01H(0.99T − 14.3) + 46.3
  • Heat Index(체감온도) – NOAA 공식
  • 습구온도(Wet‑Bulb) – Stull 근사식
  • WBGT
    WBGT = 0.7 × WetBulb + 0.3 × Temperature
  • Comfort Score(쾌적도 점수) – weather2 독자 지표
