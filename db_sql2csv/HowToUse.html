How to Use SQL → CSV Automation (weather2)

This guide explains how the SQL-to-CSV automation works inside the weather2 project. The automation consists of a BAT file, multiple PowerShell scripts, and SQL files. Users only need to modify two files: config.ps1 and sql1.ps1.

📁 Folder Location

Automation scripts are located here:
https://github.com/yahikoyama/weather2/tree/main/db_sql2csv

🧩 Overall Execution Flow

Select2CSV-citylist.bat   →   exec1.ps1   →   util-db.ps1
                                   ↓
                               sql1.ps1
                                   ↓
                               SQL Server
                                   ↓
                               city-list.csv

🟦 1. Main Batch File (Entry Point)

Select2CSV-citylist.bat

This is the main batch file. Run this file from the command prompt to start the entire automation. 

C:\weather\db_sql2csv>Select2CSV-citylist.bat

The BAT file launches PowerShell and calls exec1.ps1.

🔧 Changing the CSV Output Location (BAT)

The CSV output path is defined directly inside Select2CSV-citylist.bat. Below is the actual script used in weather2: 

PowerShell -ExecutionPolicy RemoteSigned C:\weather\db_sql2csv\exec1.ps1 > C:\weather\db_sql2csv\CSV\city-list.CSV
start notepad.exe "C:\weather\db_sql2csv\CSV\city-list.CSV"

To change where the CSV file is saved, edit the CSV path in both lines: 

PowerShell -ExecutionPolicy RemoteSigned C:\weather\db_sql2csv\exec1.ps1 > D:\MyData\city-list.CSV
start notepad.exe "D:\MyData\city-list.CSV"

This allows you to store the CSV file anywhere you prefer.

🟦 2. PowerShell Main Controller

exec1.ps1

This script controls the SQL execution flow. It loads util-db.ps1 and then calls sql1.ps1.

Do not modify this file.

🟦 3. Shared Utility Functions

util-db.ps1

This file contains database utility functions such as:

  • SQL Server connection handling
  • Command execution helpers
  • Common logging functions

Do not modify this file.

🟦 4. Files You Must Modify

config.ps1 (Database Settings)

Edit this file to configure your SQL Server environment:

  • Server name
  • Instance name
  • Database name
  • Authentication settings
$ServerInstance = ".\SQLEXPRESS"
$DatabaseName   = "WeatherDB"

sql1.ps1 (SQL Execution Target)

This file specifies which SQL file to run. Modify this file when you want to change the SQL logic. 

$SqlFile = "city_list_en.sql"

You can replace the SQL file with any script from:

Data-Extraction-SQL directory

📤 Output

The result of the SQL execution is exported as: 

city-list.csv

The output location is controlled entirely by the path inside Select2CSV-citylist.bat.
