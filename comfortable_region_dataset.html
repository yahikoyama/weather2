Weekly Comfortable Region Ranking Dataset

This dataset provides historical weekly rankings of comfortable regions around the world. The rankings are calculated using weather observations and a custom Comfort Score algorithm developed for the weather2 project.

The dataset is updated weekly and published as a CSV file for research, education, climate analysis and AI applications.

Download CSV Dataset

Dataset Overview

  • Weekly updated dataset
  • Global city and region coverage
  • CSV format
  • Historical ranking records
  • AI and machine learning friendly

Methodology

The ranking is based on a custom Comfort Score calculated from:

  • Temperature
  • Humidity
  • Discomfort Index (DI)
  • WBGT
  • Heat Index
  • Wet Bulb Temperature

Higher scores indicate more comfortable outdoor conditions.
