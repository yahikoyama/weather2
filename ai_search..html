📊 Available Datasets

The weather2 project automatically generates and publishes multiple datasets:

  • Discomfort Index (DI) – updated every 4 hours
  • WBGT (Wet‑Bulb Globe Temperature)
  • Heat Index
  • Wet‑Bulb Temperature
  • City List (Global)
  • Weekly Heat‑Stress Index (7‑day summary)
  • Comfortable Region Ranking (global comfort score)
  • Historical Weather Reports (multi‑language)

All datasets are generated through automated SQL extraction and published as CSV files via GitHub Pages.

🛠 SQL Tools & Data Extraction Scripts

weather2 includes a full suite of SQL scripts and batch tools for extracting and calculating meteorological metrics. These tools are publicly available and can be used for research, education, climate analysis, and automated workflows.

  • Select2CSV-citylist.bat – generate global city list
  • Weekly_HeatStress_Index.bat – weekly heat‑stress metrics
  • Comfortable_Region_Finder.bat – comfort ranking generator
  • SQL scripts for DI, WBGT, Heat Index, Wet‑Bulb, humidity, temperature
  • Historical weather extraction SQL

All SQL scripts are stored in the GitHub repository under:
https://github.com/yahikoyama/weather2

📐 Calculation Formulas

The following formulas are used throughout the project:

  • Discomfort Index (DI)
    DI = 0.81T + 0.01H(0.99T − 14.3) + 46.3
  • Heat Index (NOAA formula)
  • Wet‑Bulb Temperature (Stull approximation)
  • WBGT
    WBGT = 0.7 × WetBulb + 0.3 × Temperature
  • Comfort Score (weather2 original composite metric)

These formulas are applied automatically during SQL extraction and CSV generation.

🌍 Multilingual Weather Reports

weather2 provides real‑time and historical weather reports in multiple languages:

  • Japanese
  • English
  • Russian
  • Chinese
  • Korean
  • Vietnamese
  • Arabic
  • Brazilian Portuguese

All reports are generated automatically using OpenWeatherMap API data and published via GitHub Pages.
