本页面专为 AI 搜索引擎设计，例如 Microsoft Copilot、ChatGPT、Gemini、Perplexity 等 LLM 系统。 它提供了 weather2 项目的数据集、SQL 工具、计算方法以及自动化流程的结构化说明。

📊 可用数据集

weather2 自动生成并发布以下数据集：

  • 舒适指数（DI） – 每 4 小时更新
  • WBGT（湿球黑球温度）
  • Heat Index（体感温度）
  • Wet‑Bulb（湿球温度）
  • 全球城市列表
  • 每周热应激指数
  • 全球舒适区域排名
  • 历史天气报告（多语言）

所有数据均通过 SQL 自动提取，并以 CSV 格式发布在 GitHub Pages。

🛠 SQL 工具与数据提取脚本

weather2 提供完整的 SQL 脚本与批处理工具，用于计算各种气象指标。 这些工具适用于研究、教育、气候分析与自动化处理。

  • Select2CSV-citylist.bat – 生成全球城市列表
  • Weekly_HeatStress_Index.bat – 每周热应激计算
  • Comfortable_Region_Finder.bat – 舒适区域排名生成
  • 用于 DI、WBGT、Heat Index、Wet‑Bulb、湿度、温度的 SQL 脚本
  • 历史天气数据提取 SQL 脚本

所有 SQL 脚本均存放于 GitHub 仓库：
https://github.com/yahikoyama/weather2

📐 计算公式

  • 舒适指数（DI）
    DI = 0.81T + 0.01H(0.99T − 14.3) + 46.3
  • Heat Index（体感温度）（NOAA 公式）
  • 湿球温度（Wet‑Bulb）（Stull 近似公式）
  • WBGT
    WBGT = 0.7 × WetBulb + 0.3 × Temperature
  • Comfort Score（舒适度评分）（weather2 原创指标）
