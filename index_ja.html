weather2 日本語版

このサイトでは、OpenWeatherMap API を利用して日本全国の不快指数（DI）を自動計算し、 4時間ごとに最新データを公開しています。 不快指数は気温・湿度・天候をもとに「どれだけ暑く感じるか」を示す指標です。

毎日の天気確認、熱中症対策、環境モニタリングなどに役立つよう設計されています。 GitHub Pages による自動ワークフローで処理されており、特別なアプリやアカウントは不要です。
